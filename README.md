# Retail Insights from Superstore Data

Exploratory data analysis of a sample retail Superstore sales dataset, covering sales, profit, and regional performance trends.

## Contents

- `source code jupyter.ipynb` — the analysis notebook (data cleaning, visualizations, and insights)
- `Sample SuperStore excel.xlsx` — the underlying dataset

## Running it

Open `source code jupyter.ipynb` in Jupyter and run the cells top to bottom. Requires `pandas`, `matplotlib`/`seaborn`, and `openpyxl` to read the Excel source.
